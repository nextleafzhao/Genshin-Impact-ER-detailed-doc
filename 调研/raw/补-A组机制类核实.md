## A-3 批注 #5（part1.tex line 63）：「不吃防御却有独立的补偿乘区」——「有待验证」

**结论：两段拆开判。**
- **「不吃防御」：表述成立，建议保留。** T1 KQM（meropide 伤害公式速查与剧本反应通则）一致把「不参与防御区」列为月曜/星烁的通则；T2 巴哈复算 13 级灵驹飞踏（误差 <0.02%）隐含默认无防御/减防参与。
- **「却有独立的补偿乘区」：表述不清，建议改写。** 笔记 E.5 的「擢升（Elevation）」是独立乘区，但它是命之座来源，不是"补偿"语义。把"补偿"理解为"可暴击带来的期望值增益"也成立，但与「乘区」不在同一抽象层级。
  - 改写建议（待用户定调）：
    1. 删「却**有独立的补偿乘区**」整句，简化为「**且不受防御与减防影响**」——更贴近 T1 KQM 原话。
    2. 或改写为「**但等效地享受双暴乘区带来的期望值增益**」——更精确但更长。
    3. 或保留原句，加 `\cunyi` 标注待考。

**置信度：「不吃防御」T1 × 多源一致 / 「补偿乘区」用户表述待定。**

## A-5 批注 #9（figures.tex line 20）：月曜卡注「视为剧变反应；吃等级系数与元素精通，不吃双暴」——「有待验证」

**结论：表述两处需改，与通则 3 矛盾。**

- **「视为剧变反应」**：错误。剧变反应（笔记 B 节定义）= 超载 / 超导 / 感电 / 碎冰 / 扩散 / 燃烧 / 绽放 / 超绽放 / 烈绽放；月曜反应（笔记 B 节）= 月感电 / 月绽放 / 月结晶，是新增的独立第六类。改写为「视为**月曜反应**」（与表 1「伤害基准」列对齐——「等级系数（反应型）／角色面板（直伤型）」）。
- **「吃等级系数与元素精通」**：反应型部分成立（90 级等级系数 1446.85；T1 KQM），直伤型不吃等级（笔记 B1/B2/B3）。建议简化为「吃元素精通；反应型另吃等级系数」。
- **「不吃双暴」**：**与通则 3「100% 参与暴击结算」直接矛盾**。T0 五项官方原文均明确"可暴击"。**必须删除此句**。

**改写建议**：
```
视为月曜反应；反应型吃等级系数与元素精通，直伤型吃角色面板与元素精通；可暴击
```
或更简：
```
视为月曜反应；吃元素精通，反应型另吃等级系数；可暴击
```

**置信度：「视为剧变」为分类错误 / 「不吃双暴」与 T0 × 5 矛盾 / 「吃精通」部分正确。**
