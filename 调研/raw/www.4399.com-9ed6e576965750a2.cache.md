# 一、技能加点

元素战技9级=元素爆发9级>普通攻击1级。有条件可继续升1、10、10配置。

![](https://fs.img4399.com/bbs/202604/8/2026001030653/jgnyXqMboh.2535x1426.jpg~740x0)

莉奈娅的拐力都放在天赋中：15%岩减抗+满辉额外15%岩减抗+自身防御5%转场上月兆角色精通。

升级技能更多是增强莉奈娅的输出伤害（战技召唤物倍率）、以及生存方面的治疗量提升（元素爆发群奶+持续单体奶）。

![](https://fs.img4399.com/bbs/202604/8/2026001030652/sWoA6uMC9i.2535x1426.jpg~740x0)

实战中，可直接元素爆发+元素战技下场。遇到部分瘫痪减抗期较短的敌人，可考虑连续点按战技压缩伤害，打出月结晶瞬间爆发伤害，随后召唤物会进入虚弱状态，只能造成普通岩元素伤害（不影响减抗）。

※下次点按战技依旧可正常打出中锤。

# 二、武器期望对比

目前武器方面，莉奈娅可细分为2种情况。

其一，充当为多队伍副C生存位，此外武器会着重考虑全队贡献以及操作流程，如部分辅助武器的贡献：

霜结的誓金枝>95%>若水>90%>天空之翼>星鹫赤羽/最初的大魔术/飞雷之弦振>猎人之径>冬极白星>弹弓>80%>终末嗟叹之诗>西风猎弓。

※终末覆盖率太低了，西风可降低哥伦比娅充能压力。

![](https://fs.img4399.com/bbs/202604/8/2026001030655/XLjMxPeacQ.2535x1426.jpg~740x0)

其二，莉奈娅主C玩法，此时输出至上：

霜结的誓金枝>祭礼>90%。

※重锤不触发祭礼，需适当等待1-2秒让小锤触发（可观察技能CD），随后点按战技下场即可（持续输出总伤更高）。部分输出空窗期短/时间即将结束，也可选择放2次重锤~

![](https://fs.img4399.com/bbs/202604/8/2026001030650/6z3n5Q4xmX.2535x1426.jpg~740x0)

# 三、圣遗物选择

由于莉奈娅的防御转精通无上限，因此圣遗物有2套可考虑。注重自身伤害的「晨星与月的晓歌」，高防御提高精通转化以及大招治疗量的「华馆梦醒形骸记」，后者一般搭配兹白时可以考虑。

![](https://fs.img4399.com/bbs/202604/8/2026001030654/OPcsayjSKG.2535x1426.jpg~740x0)

主词条，暴击/暴击伤害头、防御/充能沙、防御杯。副词条，暴击率、暴击伤害、防御力、充能。

![](https://fs.img4399.com/bbs/202604/8/2026001030656/yHKczNqraw.2535x1426.jpg~740x0)

理之冠选暴击还是暴击伤害？取决于你是否会溢出暴击率，优先往满暴去考虑。而莉奈娅自身等级突破提升暴击率，相当于面板自带24.2%暴击，接近满暴不算太难。

![](https://fs.img4399.com/bbs/202604/8/2026001030658/VO1dFzqpW8.2535x1426.jpg~740x0)

时之沙呢？这一块则看情况，搭配攻击C（娜维娅/凝光等等）或者精通C（奈芙尔等等）或芙宁娜，则需要确保大招每轮开启保生存，此时要携带充能沙，达成160%+充能。搭配防御C、生命C则不需要刻意考虑，2轮1大都行。

空之杯固定为防御主词条。月曜反应不吃普通增伤，带精通仅提升莉奈娅自身伤害，防御则可以同时提升自身伤害、大招治疗、精通拐转化。

![](https://fs.img4399.com/bbs/202604/8/2026001030657/MIXYCo0inU.2535x1426.jpg~740x0)

# 四、配队建议

【完整月结晶】兹白+莉奈娅+哥伦比娅+叶洛亚/五郎。

※4号位，谁满命先用谁，都满则优先叶洛亚。

【月绽放替选】奈芙尔+菈乌玛+哥伦比娅+莉奈娅。

※有输出、有治疗、有精通拐，确实可以当4号位用。

【搭配老岩C】娜维娅/荒泷一斗/诺艾尔/凝光+莉奈娅+哥伦比娅+伊涅芙/2命芙宁娜/叶洛亚/五郎。

※老岩C要挂岩强的，提高月笼触发频率。

【莉奈娅主C】莉奈娅+哥伦比娅+伊涅芙/叶洛亚/五郎+砂糖/钟离。

![](https://fs.img4399.com/bbs/202604/8/2026001030660/ErpKxYWLkT.2535x1426.jpg~740x0)

# 五、加金提升

换专武提升5-15%，1命10%+，2命20%+，4命低于10%，6命40%+。最终可排出以下顺序：莉奈娅本体->01或20->补全21->止步或直上61配置。

![](https://fs.img4399.com/bbs/202604/8/2026001030659/Y7JElG2k0Q.2535x1426.jpg~740x0)

莉奈娅整个命座并没有机制方面的质变，更多体现在纯数值方面，比较适合2种玩家考虑。①喜欢莉奈娅，且想玩主C路线；②已有至少21兹白，可考虑继续加金莉奈娅。
