## 元素共鸣

### 介绍

队伍满员状态（角色数不少于4）下，根据队伍配置的角色元素类型，获得对应元素的元素共鸣效果。这些效果只要满足条件，便会对全队生效。如果有多个元素共鸣，则这些元素共鸣一起生效。  
目前共有8种元素共鸣效果，下面分别列出（元素符号前面的“2”表明触发该元素共鸣需要至少2名该元素角色）。
需要注意的是：

| 条件 | 名称 | 元素共鸣效果 |
| --- | --- | --- |
| 2卡牌UI-元素-火.png | 热诚之火 | 卡牌UI-元素-冰.png冰元素附着的持续时间下降40%。攻击力提高25%。 |
| 2卡牌UI-元素-水.png | 愈疗之水 | 卡牌UI-元素-火.png火元素附着的持续时间下降40%。生命值上限提升25%。 |
| 2卡牌UI-元素-风.png | 迅捷之风 | 体力消耗降低15%，移动速度提升10%，技能冷却时间缩短5%。 |
| 2卡牌UI-元素-雷.png | 强能之雷 | 卡牌UI-元素-水.png水元素附着的持续时间下降40%。触发[元素反应-超导.png](/ys/%E5%85%83%E7%B4%A0%E5%8F%8D%E5%BA%94 "元素反应")[超导](/ys/%E5%85%83%E7%B4%A0%E5%8F%8D%E5%BA%94#超导 "元素反应")、[元素反应-超导.png](/ys/%E5%85%83%E7%B4%A0%E5%8F%8D%E5%BA%94 "元素反应")*[星超导 星超导](/ys/%E5%85%83%E7%B4%A0%E5%8F%8D%E5%BA%94 "元素反应")*、[元素反应-超载.png](/ys/%E5%85%83%E7%B4%A0%E5%8F%8D%E5%BA%94 "元素反应")[超载](/ys/%E5%85%83%E7%B4%A0%E5%8F%8D%E5%BA%94 "元素反应")、[元素反应-感电.png](/ys/%E5%85%83%E7%B4%A0%E5%8F%8D%E5%BA%94 "元素反应")[感电](/ys/%E5%85%83%E7%B4%A0%E5%8F%8D%E5%BA%94#感电 "元素反应")、[元素反应-感电.png](/ys/%E5%85%83%E7%B4%A0%E5%8F%8D%E5%BA%94 "元素反应")*[月感电 月感电](/ys/%E5%85%83%E7%B4%A0%E5%8F%8D%E5%BA%94 "元素反应")*、[元素反应-激化.png](/ys/%E5%85%83%E7%B4%A0%E5%8F%8D%E5%BA%94 "元素反应")[原激化](/ys/%E5%85%83%E7%B4%A0%E5%8F%8D%E5%BA%94 "元素反应")、[元素反应-激化.png](/ys/%E5%85%83%E7%B4%A0%E5%8F%8D%E5%BA%94 "元素反应")[卡牌UI-元素-雷.png](/ys/%E5%85%83%E7%B4%A0%E5%8F%8D%E5%BA%94 "元素反应")[超激化](/ys/%E5%85%83%E7%B4%A0%E5%8F%8D%E5%BA%94 "元素反应")、元素反应-草原核.png[卡牌UI-元素-雷.png](/ys/%E5%85%83%E7%B4%A0%E5%8F%8D%E5%BA%94 "元素反应")[超绽放](/ys/%E5%85%83%E7%B4%A0%E5%8F%8D%E5%BA%94 "元素反应")反应时，有100%概率掉落1个卡牌UI-元素-雷.png雷元素微粒，冷却时间5秒。 |
| 2卡牌UI-元素-草.png | 蔓生之草 | 元素精通提升50点。触发[元素反应-燃烧.png](/ys/%E5%85%83%E7%B4%A0%E5%8F%8D%E5%BA%94 "元素反应")[燃烧](/ys/%E5%85%83%E7%B4%A0%E5%8F%8D%E5%BA%94 "元素反应")、[元素反应-激化.png](/ys/%E5%85%83%E7%B4%A0%E5%8F%8D%E5%BA%94 "元素反应")[原激化](/ys/%E5%85%83%E7%B4%A0%E5%8F%8D%E5%BA%94 "元素反应")、[元素反应-绽放.png](/ys/%E5%85%83%E7%B4%A0%E5%8F%8D%E5%BA%94 "元素反应")[绽放](/ys/%E5%85%83%E7%B4%A0%E5%8F%8D%E5%BA%94 "元素反应")、[元素反应-绽放.png](/ys/%E5%85%83%E7%B4%A0%E5%8F%8D%E5%BA%94 "元素反应")*[月绽放 月绽放](/ys/%E5%85%83%E7%B4%A0%E5%8F%8D%E5%BA%94 "元素反应")*反应后，队伍中附近的所有角色元素精通提升30点，持续6秒。触发[元素反应-激化.png](/ys/%E5%85%83%E7%B4%A0%E5%8F%8D%E5%BA%94 "元素反应")[卡牌UI-元素-雷.png](/ys/%E5%85%83%E7%B4%A0%E5%8F%8D%E5%BA%94 "元素反应")[超激化](/ys/%E5%85%83%E7%B4%A0%E5%8F%8D%E5%BA%94 "元素反应")、[元素反应-激化.png](/ys/%E5%85%83%E7%B4%A0%E5%8F%8D%E5%BA%94 "元素反应")[卡牌UI-元素-草.png](/ys/%E5%85%83%E7%B4%A0%E5%8F%8D%E5%BA%94 "元素反应")[蔓激化](/ys/%E5%85%83%E7%B4%A0%E5%8F%8D%E5%BA%94 "元素反应")、元素反应-草原核.png[卡牌UI-元素-雷.png](/ys/%E5%85%83%E7%B4%A0%E5%8F%8D%E5%BA%94 "元素反应")[超绽放](/ys/%E5%85%83%E7%B4%A0%E5%8F%8D%E5%BA%94 "元素反应")、元素反应-草原核.png[卡牌UI-元素-火.png](/ys/%E5%85%83%E7%B4%A0%E5%8F%8D%E5%BA%94 "元素反应")[烈绽放](/ys/%E5%85%83%E7%B4%A0%E5%8F%8D%E5%BA%94 "元素反应")反应后，队伍中附近的所有角色元素精通提升20点，持续6秒。以上效果的持续时间独立计算。 |
| 2卡牌UI-元素-冰.png | 粉碎之冰 | 卡牌UI-元素-雷.png雷元素附着的持续时间下降40%。攻击卡牌UI-元素-冰.png冰元素附着或[元素反应-冻结.png](/ys/%E5%85%83%E7%B4%A0%E5%8F%8D%E5%BA%94 "元素反应")[冻结](/ys/%E5%85%83%E7%B4%A0%E5%8F%8D%E5%BA%94#冻结 "元素反应")状态下的敌人时，暴击率提高15%。 |
| 2卡牌UI-元素-岩.png | 坚定之岩 | 护盾强效提升15%。此外，角色处于护盾庇护下时，或附近存在[元素反应-结晶-水.png](/ys/%E5%85%83%E7%B4%A0%E5%8F%8D%E5%BA%94 "元素反应")*[月结晶 月结晶](/ys/%E5%85%83%E7%B4%A0%E5%8F%8D%E5%BA%94 "元素反应")*反应产生的月笼时，具有如下特性：造成的伤害提升15%；角色对敌人造成伤害时，会使敌人的卡牌UI-元素-岩.png岩元素抗性降低20%，持续15秒。 |
| 4不同元素 | 交织之护 | 所有元素抗性提升15%，物理抗性提升15%。 |
