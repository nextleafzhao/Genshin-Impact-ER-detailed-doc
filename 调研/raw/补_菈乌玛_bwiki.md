| 当夜晚降临，霜月之子便生活在一座「塔」中。  塔顶是那轮似乎从未变过的满月，塔底是希汐岛的土地。墙壁由皎白的月光筑成，随便谁都能从那光辉中穿过。  月神啊，多么温柔。即便不被所有人信仰，即便不被所有人知晓，也并不吝惜播撒她的恩惠。  霜月之子的老祭司这般说道。此言过后，低声的祝祷隐约响起，而菈乌玛的声音并不在其中。  她静静的望着那轮满月，眼中别无其他，如同最为虔诚的信徒。  她无疑也在这座塔中，自出生起便成长、生活在这由月亮、月光与月神信众共同筑就的塔中。  她仍看着那轮天幕之上的满月，心想有句话或许说得对：人类永远无法建成通天塔。 |
| 角色故事1 （解锁条件：好感2级） |
| 「她于暮春之月的第一轮满月当空时坠地，草木伴随她的第一声哭泣成长。  「欢笑吧，起舞吧，在新生咏月使的啼哭声中——  「为她被月光浸染的角和血，因她将在月神的目光下酣睡。」  …菈乌玛合上霜月之子的记事簿。  她总是不由自主地翻到记录着她出生之时的那页，试图在泛黄的笔记中感受信众们的喜悦。  就像天才总在平庸的人群中出现，身为普通霜月之子成员的一对夫妻诞下了菈乌玛这样异于常人的个体。根据记载，「她的眼眸如月汐，角冠在月光下生长，银血似水中月影」，是「月神赐予信众的奇迹」。  在世界的边陲，这似乎已被时间遗忘的「霜月之子」中，菈乌玛成为了那个雪中送炭，却又不合时宜的希望。她被欣喜若狂的信众们当作了月神并未将他们抛弃的佐证，成为了一个活着的符号。  极少有人能在诞生时就被指认为咏月使的继任者，身为霜月之子的一员，菈乌玛应当喜悦，更应当视此责任为殊荣。  正如记事簿中接下来写着的那段话，那段菈乌玛至今已熟记于心的文字：  「…她将在月神的目光下酣睡。  「而当月亮沉眠、太阳升起，她将为无上的霜月女神代言。」 |
| 角色故事2 （解锁条件：完成「尘与灯的挽歌」剧情） |
| 只要生得够早，又活得够久，并且还不曾被更超越的存在抹去禁忌的回忆，那么一定会有人记得（提瓦特的确有这样的存在）：在葬火之战还未发生前，受命于尼伯龙根的三月女神曾与天空岛的法则和谐共处过一段时间。  当然如果拿此事去问天空岛，高天之上或许会予以不置可否的答复。三月曾是守护提瓦特的三颗卫星，三月女神则是星球意志的代行。天空岛的法则一度十分「宽容」，不一定非要排除异己。  而对三月女神而言，她们的全部职责只在于维系星球的存续与运转。于是月光便继续照亮着提瓦特的大地。只可惜安分守己的她们最终也不可能置身事外；上位者的争斗总是会波及一部分下属，这也是没有办法的事情。  如果那时黄金的亥珀波瑞亚还留有幸存者，那他们一定有很多话要讲，只可惜作为他们遗民的霜月之子并不了解祖先的怨仇，现在只能空对明月祈祷。  在这群可怜的盲从者中，菈乌玛是相对幸运的一位。她虽不完全知晓以上种种，仍能清晰地感知到，那天上的满月虽然明亮，却是那样死气沉沉；而真正牵动她心绪、让她角冠生长的潮汐，却在更遥远、更无法触及的地方。  这份感受曾困扰她多时。就像让一个人对着画布上的苹果去祈求它能让自己饱腹，菈乌玛总觉得心神不宁。  好在这个问题现在终于有了答案，虽然天空突然「变成」假的了，她却证实了自己感受的真实性。  菈乌玛从不觉得无知是件好事，即便真相更令人无所适从。此生本无法随心所欲，此生本就由矛盾造就，但至少这一切不必掺杂谎言和隐瞒。 |
| 角色故事3 （解锁条件：完成「尘与灯的挽歌」剧情） |
| 菈乌玛曾给自己定下一些「戒律」。这些戒律在他人眼中或许不可理喻，所以很久以来，她并未和任何人提起。  她想，我绝不可说谎。对于不确定的问题，沉默亦是一种回答，但不能为了粉饰太平而编造事实；尤其当咏月使的身份可以让信众们轻而易举地相信她所说的任何东西时，撒谎更是一件不可饶恕的罪过。  ——然而对着天上虚假的月亮祈祷，这是谎言的一种吗？她难以判断，又坐立难安。  她想，我绝不可动怒。苍林的圣女应当是温柔和慈爱的，霜月的女神亦然，月下的湖光平静无波，那神明的使节又有何生气的权力？即便月矩力的潮汐常令人心烦意乱，但作为一个合格的领导者，理应学会控制自己的情绪。  ——然而有些情绪并不因潮汐而起。虽然她并没有大喊大叫地发脾气，但痛揍敌人一顿算是动怒吗？她有些紧张地搓着手指，不知该向谁去征询意见。  她想，我绝不可改变。在几千几百年的演变中，霜月之子早已和黄金时代相去甚远，任何波动都有可能折断这根岌岌可危的旧枝。尤其在信众们将「特别」的自己当作希望的此时此刻，她更得保持好一名咏月使该有的形象。  ——然而她已将月亮与天空的真相向众人道出。这次她不用向任何人询问，都知道改变已然产生。  事已至此，似乎三条戒律都形同虚设。菈乌玛终于泄了气，在某个晚上将这些难以启齿的话向她的动物朋友们和盘托出。  如她所料，小动物们热情接待了她，并如往常一般七嘴八舌地畅聊人生——指菈乌玛的人生。  它们很够朋友，先是肯定了菈乌玛的诚实可靠，然后赞美了她的温柔体贴，最后称菈乌玛一向如此，并未有任何改变。（菈乌玛听了有些开心，但又愈发局促，恨不得立刻多变出两条腿跑掉。）  最后的最后，有一只常去那夏镇玩耍的小猫总结道：「如果非要说哪里有问题嘛…阿舍鲁说过，你这种毛病叫固执！」 |
| 角色故事4 （解锁条件：好感5级） |
| 菈乌玛曾主持过一场订婚仪式。  出席者有三：时不时来旗舰酒馆帮忙的年轻冒险家，正准备和这名冒险家一起离开挪德卡莱的霜月之子少女，以及神秘出现在酒馆客房的咏月使。  三个人在狭小的房间里面面相觑。一时间没人讲话，男子从口袋里哆嗦着掏出一条手帕，递给紧张的少女擦汗。  此情此景下，菈乌玛反而成了最淡定自若的一位。  菈乌玛显然明白是怎么回事，但少女还是磕磕绊绊地解释起来：「…不是想要不告而别的意思，我留了信在枕头下…唉反正我也没什么家人在这边，都不一定会被人看见…」  年轻男子也赶忙保证：「我会对她好的，也会常带她回来探望朋友！我不是不负责任的人，你看，我连婚都求过了…」  菈乌玛看着他们握在一起的手，和手上成对的戒指，眉头紧皱。少女又开始流汗了，似乎有拉着未婚夫拔腿就跑的趋势，奈何菈乌玛站在门口，算上角的高度，把房门堵了个严严实实。  菈乌玛思考了一阵，在两个人开始考虑翻窗时终于说道：「第一，我知道你们交往有一阵了；第二，我没说不能离开；第三，订婚必须要有仪式。你们等在这里不许动，我去准备。」  「…啊？」  于是菈乌玛在半小时内凑齐了订婚仪式需要的所有东西（包含不知从哪里搞来的凌晨三点开放的宿影花），在拥挤的客房里（四处散落着收拾到一半的行李），为两位有情人主持了完全符合霜月之子习俗的全套订婚仪式（菈乌玛负责扮演了司仪、女方亲属，以及祭司等全部角色）。  等一切结束后，少女终于松了口气：「原来菈乌玛大人在意的是仪式吗，真是在意想不到的地方非常固执呢…」  「这是固执吗？这是必须要做的事情。」菈乌玛偏过头，略感不解。  「对了，还有一件必须要做的事。这位先生，请留下你的名字、姓氏、中间名，以及固定的联系地址。我需要寄圣餐给你们。」 |
| 角色故事5 （解锁条件：完成「尘与灯的挽歌」剧情） |
| 菈乌玛曾主持过一场葬礼。  死者是一名相当长寿的长老，在这苦寒之地度过了整整一百零二年的岁月。在菈乌玛的记忆里，她始终是这种模样，笑眯眯的，皱纹堆在眼角，似乎从未变过。  在成为咏月使的日子里，菈乌玛和这位长老学习了不少知识。在老人临行前的最后一个夜晚，菈乌玛安静地陪伴在她的床畔。  在霜月之子的教义中，死亡并不是终点，生命始终在「流变」。亲朋好友只是在合适的时机回归自然，也定会在未来与大家重逢。  如果能在洁白的月光下安然「入睡」，便是得到了月神赐予的至高祝福。本该是这样一个平静的夜晚，月光如千百年来一般，鸟兽也默然。  直到老人轻轻说道：「咏月使大人…月神，其实并不存在吧。」  这不是一个疑问句，老人平稳的语气似乎已经断定事实即是如此：整整一百零二年的岁月中，月神从未回应过她的祷告。  菈乌玛一时间想到很多：她想到沐光之台上的巨大神像，她想到那位与神像如出一辙的少女…她想说，不是的，月神真的存在，只是和大家想象的不同。  月神，看起来也只是和您一样的「人」，一样地度过这一百零二年的孤独寒夜。  「没关系的，您不用回答。」在菈乌玛的犹豫中，老人轻轻地摇头，「无论月神是不愿出现，还是并不存在，都不影响时间的流逝。」  「『霜月之子』的生活，靠我们自己就可以过得很好了，不是吗？」老人轻轻地握住菈乌玛的手，似乎她才是需要被安慰的那个，「所以放松眉头，笑一笑吧，咏月使大人。您已经做得很好了。」  「不用为任何人的缺席而悲伤…『死亡固然愤怒，但愤怒也徒然。』」  菈乌玛不禁露出一个微笑，反握住老人的手。  她等待着，等待着无痛而宁静的睡眠将这位老人带回温暖的生命之海，在那海的中央，一定倒映着三轮圆满的月。 |
| 纸星星 （解锁条件：好感4级） |
| 纸星星的折法是菈乌玛从霜月之子的小孩们那里学来的，而小孩子们又是从希汐岛外学来的。  能教超级厉害的咏月使大人做事，孩子们显得格外热心。他们主动裁好五颜六色的纸条，又取来大个的玻璃罐。  「镇上的姐姐说，不要因为贪心把星星做得太大，不然中间空空的，很容易凹进去。」一个小姑娘笑嘻嘻地说，「尤其那个姐姐有一条铁手臂，特别容易一使劲就把星星捏扁了！」  菈乌玛听得格外认真，做得也又快又好。她把自己折好的那堆星星和孩子们的放在同一个罐子里，于是那个无聊的玻璃罐也变得热闹起来。  以菈乌玛现在的身份和年纪，沉迷于做这种小手工似乎有些幼稚了。但话又说回来，在她年幼时在书库中埋头苦读的时候，也没有人觉得太成熟呀。  于是菈乌玛便心安理得地，和孩子们窝在房间角落，折了整整三大罐纸星星。 |
| 月之轮（解锁条件：好感6级） |
| 菈乌玛非常感谢月之轮的存在，也非常高兴自己能拥有一枚，但说实话，这东西让她着实有些困扰，因为她不记得自己是如何获得它的了。  莎莱卡奶奶说，她的这枚月之轮是从襁褓中掉出来的。虽然父母当时正被新生命的到来冲昏头脑，记忆有些模糊，但也确认了这个说法。  如果将她的烦恼说给其他人听，他们一定会很困惑：出生起就拥有了一枚月之轮，这不是一件好事吗？有什么值得烦忧的吗？  似乎除了她自己以外，没有人觉得一个婴儿身边出现一枚月之轮有什么问题：「如果是咏月使大人，身上无论发生什么奇迹都很正常呢。」  菈乌玛有口难辩。想要知道一件事的起源是多么自然、多么符合人类好奇心的事情啊，但她查遍了书库的资料，都没能找到令人满意的解答。  她一直没有放下这个问题，以至于在后来见到月之少女时，忍不住询问了此事。  库塔尔的回答极其简单：「哦？」  …因此，最接近的解释还是来自「亥珀波瑞亚」。黄金国历史悠久，可追溯至天空中升起三轮月亮的时期。他们学会了利用月亮的潮汐驱动魔法，但也因此受月之潮汐的影响，有些人的头顶上长出了类似鹿角的角冠。  然而在那个时候，世界上有月之轮这种东西吗？  菈乌玛就这样皱眉思考，大概是不小心自言自语了起来，引得一个路过的小孩大声问道：「菈乌玛大人，你是因为有了月之轮，头上的角才这么长的吗？」  菈乌玛眉头皱得更紧了：「这个…应该…抱歉，我不清楚。」  让小孩失望肯定是菈乌玛不想见到的事情，但意外的是，小朋友似乎并没有因为问题得不到解答而感到沮丧。  「哦！」他恍然大悟，「难道其实是因为头上的角最长，菈乌玛姐姐才拿到了月之轮的吗？」  有那么一瞬间，菈乌玛从内心深处想要接受这个答案。多么巧妙啊，这从前到后、再从后到前的因果轮回，似乎可以拿来解释（搪塞）很多问题。  然后她马上制止了自己，以免陷入谎言的陷阱。  又或许这就是这枚月之轮的作用，是对她的警戒、限制，以及责任的象征。  于是她将那枚令她不解的月之轮握在手心，在心中又默念了一遍三条戒律。 |

镜中有月，月碎水中  
 「在我们这位好心咏月使大人的手下，任何无辜的人和兽都不会被伤害…唉，可是弱肉强食的法则都不管用，某些习惯了食肉的野兽可要受苦喽。」——[![奈芙尔](https://patchwiki.biligame.com/images/ys/thumb/3/3a/19eatdsn9h7cycfi2rdo68n1etp8zyo.png/30px-%E5%A5%88%E8%8A%99%E5%B0%94.png)](/ys/%E5%A5%88%E8%8A%99%E5%B0%94 "奈芙尔")  [奈芙尔](/ys/%E5%A5%88%E8%8A%99%E5%B0%94 "奈芙尔")    
 ==========  
 作为挪德卡莱所在之地的原住民，在如今的事态下，「霜月之子」反而显得格格不入。  
 他们过于古老，过于刻板，信仰着一位自己也没见过的神明。  
 他们相信苍林的树影是他们庇护所，相信满月的辉光将驱散所有的伤病。  
 他们向月亮祈祷，问霜月的女神啊，您将何时回应我们的愿望？  
 得不到回答，他们便又问，咏月使大人啊，月神将何时回应我们的愿望？  
 于是菈乌玛从树影中走出，走到月光之下。  
 于是教众们朝着她光辉的角冠与银血的图腾行礼，于是她成为了那位消失的神明的代理。

#### 贰·故事

[![](https://patchwiki.biligame.com/images/ys/thumb/9/95/8gsy9dqcx04jm8l0r2ls1y5rpom9xm9.gif/240px-%E8%A7%92%E8%89%B2%E8%8F%88%E4%B9%8C%E7%8E%9B%E5%AE%98%E6%96%B9%E6%95%85%E4%BA%8B%E5%9B%BE.gif)](/ys/%E6%96%87%E4%BB%B6:%E8%A7%92%E8%89%B2%E8%8F%88%E4%B9%8C%E7%8E%9B%E5%AE%98%E6%96%B9%E6%95%85%E4%BA%8B%E5%9B%BE.gif)

菈乌玛官方故事图

当夜晚降临，  
霜月之子便生活在一座「塔」中。  
  
 塔顶是那轮似乎从未变过的满月，  
 塔底是希汐岛的土地。  
 墙壁由皎白的月光筑成，  
 随便谁都能从那光辉中穿过。

月神啊，多么温柔。  
 即便不被所有人信仰，  
 即便不被所有人知晓，  
 也并不吝惜播撒她的恩惠。

霜月之子的老祭司这般说道。  
 此言过后，低声的祝祷隐约响起，  
 *而菈乌玛的声音并不在其中。*

  

---

  

她静静的望着那轮满月，  
 眼中别无其他，  
 如同最为虔诚的信徒。  
  
 她无疑也在这座塔中，  
 自出生起便成长、生活在这由月亮、  
 月光与月神信众共同筑就的塔中。  
  
 她仍看着那轮天幕之上的满月，  
 心想有句话或许说得对：  
 *人类永远无法建成通天塔。*

### 角色考据

德鲁伊（英文：Druid）是古代凯尔特文化中最重要的祭司阶层。他们是宗教仪式的主持者，负责祭祀诸神、解释神谕、执行献祭，在凯尔特多神信仰体系中居于核心地位。德鲁伊们掌握自然知识、天文、医学、诗歌、法律与历史。他们常与橡树、藤蔓、森林与河流等自然元素紧密相连，自然崇拜是他们宗教仪式的重要部分。在现代奇幻文艺作品中，德鲁伊被塑造成智慧、自然魔法与神秘的象征。例如动视暴雪旗下的游戏作品中就经常出现德鲁伊这一职业（魔兽13个职业和炉石11个职业之一）。亲近自然的他们操纵植物与火山飓风等自然法术，或是变身成各种猛禽凶兽咕！进行战斗。《魔兽争霸III》可以培养训练德鲁伊的种族“暗夜精灵”在亲近大自然的同时，更是信仰月神艾露恩。
