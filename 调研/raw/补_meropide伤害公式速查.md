## 普通伤害

伤害=(倍率×属性×普通大权区+普通羽毛区+激化固定增伤)×(1+暴击率×暴击伤害)×(1+普通增伤)×抗性系数×防御系数×增幅系数\text{伤害} = (\text{倍率} \times \text{属性} \times \text{普通大权区} + \text{普通羽毛区} + \text{激化固定增伤}) \times (1 + \text{暴击率} \times \text{暴击伤害}) \times (1 + \text{普通增伤}) \times \text{抗性系数} \times \text{防御系数} \times \text{增幅系数}伤害=(倍率×属性×普通大权区+普通羽毛区+激化固定增伤)×(1+暴击率×暴击伤害)×(1+普通增伤)×抗性系数×防御系数×增幅系数

### 激化固定增伤

激化固定增伤=反应基础值×激化基础系数×(1+5×精通精通+1200+激化增伤)\text{激化固定增伤} = \text{反应基础值} \times \text{激化基础系数} \times \left(1 + \frac{5 \times \text{精通}}{\text{精通} + 1200} + \text{激化增伤}\right)激化固定增伤=反应基础值×激化基础系数×(1+精通+12005×精通​+激化增伤)

| 反应类型 | 激化基础系数 |
| --- | --- |
| 超激化 | 1.15 |
| 蔓激化 | 1.25 |

### 防御系数

防御系数=角色等级+100(角色等级+100)+(怪物等级+100)×(1−减防)×(1−无视防御)\text{防御系数} = \frac{\text{角色等级} + 100}{(\text{角色等级} + 100) + (\text{怪物等级} + 100) \times (1 - \text{减防}) \times (1 - \text{无视防御})}防御系数=(角色等级+100)+(怪物等级+100)×(1−减防)×(1−无视防御)角色等级+100​

### 增幅系数

增幅系数=增幅基础系数×(1+2.78×精通精通+1400+增幅增伤)\text{增幅系数} = \text{增幅基础系数} \times \left(1 + \frac{2.78 \times \text{精通}}{\text{精通} + 1400} + \text{增幅增伤}\right)增幅系数=增幅基础系数×(1+精通+14002.78×精通​+增幅增伤)

| 反应类型 | 增幅基础系数 |
| --- | --- |
| 水打火 / 火打冰 | 2 |
| 火打水 / 冰打火 | 1.5 |

## 剧变伤害

剧变伤害=(反应基础值×剧变基础系数×(1+16×精通精通+2000+剧变增伤)+剧变羽毛区)×抗性系数\text{剧变伤害} = \left(\text{反应基础值} \times \text{剧变基础系数} \times \left(1 + \frac{16 \times \text{精通}}{\text{精通} + 2000} + \text{剧变增伤}\right) + \text{剧变羽毛区}\right) \times \text{抗性系数}剧变伤害=(反应基础值×剧变基础系数×(1+精通+200016×精通​+剧变增伤)+剧变羽毛区)×抗性系数

剧变反应伤害包含：超载、超导、感电、燃烧、碎冰、扩散、绽放、超绽放、烈绽放。

该公式计算的是角色对敌人触发的剧变反应伤害。

**剧变增伤**：举例：**翠绿之影**四件套效果提供的“扩散反应造成的伤害提升60%”等。

**剧变基础系数**：

| 反应类型 | 剧变基础系数 |
| --- | --- |
| 燃烧 | 0.25 |
| 扩散 | 0.6 |
| 超导 | 1.5 |
| 感电 | 2 |
| 绽放 | 2 |
| 超载 | 2.75 |
| 碎冰 | 3 |
| 烈绽放 / 超绽放 | 3 |

**剧变羽毛区**：梦见月瑞希1命等。

扩散反应伤害可以继续触发增幅反应（融化/蒸发），以进一步提升伤害。

## 月曜伤害

### 月曜基础系数

| 伤害类型 | 月曜基础系数 |
| --- | --- |
| 月绽放 | 1 |
| 月感电 | 3 |
| 月结晶 | 1.6 |

### 直伤月曜伤害

直伤月曜伤害=(倍率×属性×月曜基础系数×(1+月曜基础增伤)×(1+6×精通精通+2000+月曜增伤)×月曜大权区+直伤月曜羽毛区)×(1+暴击率×暴击伤害)×抗性系数×(1+月曜擢升)\text{直伤月曜伤害} = \left(\text{倍率} \times \text{属性} \times \text{月曜基础系数} \times (1 + \text{月曜基础增伤}) \times \left(1 + \frac{6 \times \text{精通}}{\text{精通} + 2000} + \text{月曜增伤}\right) \times \text{月曜大权区} + \text{直伤月曜羽毛区}\right) \times (1 + \text{暴击率} \times \text{暴击伤害}) \times \text{抗性系数} \times (1 + \text{月曜擢升})直伤月曜伤害=(倍率×属性×月曜基础系数×(1+月曜基础增伤)×(1+精通+20006×精通​+月曜增伤)×月曜大权区+直伤月曜羽毛区)×(1+暴击率×暴击伤害)×抗性系数×(1+月曜擢升)

直伤月曜伤害包括：直伤月绽放、直伤月感电、直伤月结晶。

**月曜基础增伤**：举例：伊涅芙天赋**月兆祝赐·象拟中继**提供的至多14%月曜基础增伤。

**月曜增伤**：举例：伊涅芙1命带来的至多50%月曜增伤。

**月曜大权区**：举例：当前仅包括奈芙尔固有天赋**月下的豪赌**中**伪秘之帷**的增伤效果。

**直伤月曜羽毛区**：举例：菈乌玛的**苍色祷歌**，兹白固有天赋**月下素娥降仙**提供的**太阴降**效果，少女四命等。

**月曜擢升**：月曜擢升之间互相加算。

### 反应月曜伤害

单人反应月曜伤害=(反应基础值×月曜基础系数×(1+月曜基础增伤)×(1+6×精通精通+2000+月曜增伤)×月曜大权区+反应月曜羽毛区)×(1+暴击率×暴击伤害)×抗性系数×(1+月曜擢升)\text{单人反应月曜伤害} = \left( \text{反应基础值} \times \text{月曜基础系数} \times (1 + \text{月曜基础增伤}) \times \left(1 + \frac{6 \times \text{精通}}{\text{精通} + 2000} + \text{月曜增伤}\right) \times \text{月曜大权区} + \text{反应月曜羽毛区}\right) \times (1 + \text{暴击率} \times \text{暴击伤害}) \times \text{抗性系数} \times (1 + \text{月曜擢升})单人反应月曜伤害=(反应基础值×月曜基础系数×(1+月曜基础增伤)×(1+精通+20006×精通​+月曜增伤)×月曜大权区+反应月曜羽毛区)×(1+暴击率×暴击伤害)×抗性系数×(1+月曜擢升)

最终伤害=0.6×最高单人伤害+0.3×第二高单人伤害+0.05×第三高单人伤害+0.05×第四高单人伤害\text{最终伤害} = {0.6} \times \text{最高单人伤害} + {0.3} \times \text{第二高单人伤害} + {0.05} \times \text{第三高单人伤害} + {0.05} \times \text{第四高单人伤害}最终伤害=0.6×最高单人伤害+0.3×第二高单人伤害+0.05×第三高单人伤害+0.05×第四高单人伤害

直伤星烁伤害=(倍率×属性×星烁基础系数×(1+星烁基础增伤)×(1+6×精通精通+2000+星烁增伤)×星烁大权区+直伤星烁羽毛区)×(1+暴击率×暴击伤害)×抗性系数×(1+星烁擢升)\text{直伤星烁伤害} = \left(\text{倍率} \times \text{属性} \times \text{星烁基础系数} \times (1 + \text{星烁基础增伤}) \times \left(1 + \frac{6 \times \text{精通}}{\text{精通} + 2000} + \text{星烁增伤}\right) \times \text{星烁大权区} + \text{直伤星烁羽毛区}\right) \times (1 + \text{暴击率} \times \text{暴击伤害}) \times \text{抗性系数} \times (1 + \text{星烁擢升})直伤星烁伤害=(倍率×属性×星烁基础系数×(1+星烁基础增伤)×(1+精通+20006×精通​+星烁增伤)×星烁大权区+直伤星烁羽毛区)×(1+暴击率×暴击伤害)×抗性系数×(1+星烁擢升)

### 反应星烁伤害

单人反应星烁伤害=(反应基础值×星烁基础系数×(1+星烁基础增伤)×(1+6×精通精通+2000+星烁增伤)×星烁大权区+反应星烁羽毛区)×(1+暴击率×暴击伤害)×抗性系数×(1+星烁擢升)\text{单人反应星烁伤害} = \left(\text{反应基础值} \times \text{星烁基础系数} \times (1 + \text{星烁基础增伤}) \times \left(1 + \frac{6 \times \text{精通}}{\text{精通} + 2000} + \text{星烁增伤}\right) \times \text{星烁大权区} + \text{反应星烁羽毛区}\right) \times (1 + \text{暴击率} \times \text{暴击伤害}) \times \text{抗性系数} \times (1 + \text{星烁擢升})单人反应星烁伤害=(反应基础值×星烁基础系数×(1+星烁基础增伤)×(1+精通+20006×精通​+星烁增伤)×星烁大权区+反应星烁羽毛区)×(1+暴击率×暴击伤害)×抗性系数×(1+星烁擢升)

最终伤害=0.6×最高单人伤害+0.3×第二高单人伤害+0.05×第三高单人伤害+0.05×第四高单人伤害\text{最终伤害} = {0.6} \times \text{最高单人伤害} + {0.3} \times \text{第二高单人伤害} + {0.05} \times \text{第三高单人伤害} + {0.05} \times \text{第四高单人伤害}最终伤害=0.6×最高单人伤害+0.3×第二高单人伤害+0.05×第三高单人伤害+0.05×第四高单人伤害
