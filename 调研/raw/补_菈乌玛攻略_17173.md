# 《原神》月绽放体系的辅助核心！菈乌玛角色培养攻略

米游社 2025-09-10 18:57:02 [评论](#11208380_1_10009)

**导语**

# 角色介绍

菈乌玛的核心定位是绽放/月绽放体系专属辅助，具备后台挂草、减抗、增伤等功能，其机制设计围绕 "月绽放" 这一全新草水反应展开，能够显著提升队伍的绽放类反应伤害。

## 月绽放与月兆系统

菈乌玛的固有天赋 "月兆祝赐・千籁恩宠" 可将队伍触发的普通绽放反应转化为月绽放反应。需要注意的是，目前的月绽放反应与原绽放反应的区别，仅在于会额外产生“草露”供菈乌玛使用，并没有感电与月感电那样本质的区别。同样的，月绽放和月感电一样也存在直伤形式，目前仅有菈乌玛的长按战技可造成月绽放直伤，基于草露的数量以元素精通作为伤害倍率，可暴击。

菈乌玛施放元素战技后，还会根据队伍中的 "月兆" 状态（初辉 / 满辉）提供不同的增益效果：

**•****初辉状态**（1 名月兆角色）：绽放 / 超绽放 / 烈绽放双暴固定为 15%/100%，其中的暴击率可以与草神2命的加成叠加，但爆伤仍然固定为100%。

**•****满辉状态**（2 名及以上月兆角色）：全队月绽放反应双暴额外提升 10%/20%。

## 元素战技

元素战技为核心输出与减抗手段，长按战技消耗3枚草露可造成 284.5%草伤 + 820.8%倍率月绽放伤害（10级），并展开持续15秒的 "霜林圣域"

霜林圣域每2秒造成一次独立草元素附着伤害，命中敌人后降低25%草抗与水抗（持续10秒），且每次攻击均可刷新减抗时长，实战中基本可以实现全程减抗。

领域每2次攻击(即4s)产生 1 颗草元素微粒，33.3%概率多产1颗，属于间歇性充能，因为菈乌玛的充能压力还是挺大的。

## 元素爆发

基础获得18层 "苍色祷歌"，每层月咏额外增加6层（最多36层），持续15秒，CD同样15秒。

队友触发绽放类反应时消耗1层祷歌，根据菈乌玛元素精通的一定比例提升基础值。需要注意的是，元素反应的伤害公式与直伤不同，固定值加成也会有所不同，比如原绽放的基础伤害为2893.7，会根据后手角色的元素精通和队伍中其他加成计算增伤后，再加上菈乌玛提供的加成作为基础伤害，再统一计算怪物的抗性。

## 天赋加点：E＞＝Q＞A

元素战技的等级决定减抗幅度（10级固定25%草水双抗），长按战技作为主要输出手段，伤害倍率也与战技等级有关，最好升满。元素爆发升级会提高菈乌玛对绽放伤害的拐力，对全队输出的影响较大，最好升满。普攻实战中基本不会使用，无需投入资源。

# **配装建议**

## **武器：**

**1.纺夜天镜**

说明：契合菈乌玛的后台辅助定位，无需站场即可全程触发增伤；高额精通加成直接提升大招数值增益。后台触发机制与减抗效果形成联动，进一步放大队伍输出。

**2.千夜浮梦**

说明：单草阵容下，元素伤害加成与精通提升双重收益且泛用性强。但需队伍中存在多元素角色才能吃满特效，纯绽放队收益略低于专武或乌髓孑灯。

**3.乌髓孑灯**

说明：锻造获取门槛低，精通加成与绽放增伤直接对标菈乌玛的核心机制，适合搭配双草阵容且后台生效特性与圣遗物 “精精精” 词条形成完美互补。

**4.祭礼残章**

说明：缓解充能压力，保障队伍循环。在无上述武器可优先携带。

## **圣遗物：**

**1.纺月的夜歌**

**2.穹境示现之夜**

**3.饰金之梦**

注：对单情况下双草充能>185%，单草充能>240%

对双以上情况下双草充能>160%，单草充能190%

充精精比充精暴队伍总伤更高，但仅有1%，哪个好带哪个

副词条如果全追双暴总伤会下降，但是由于菈乌玛的元素战技有前置爆发，整体使用体验会更好，看自身取舍

主词条：元素充能效率/元素精通（充能武器），元素精通，元素精通/暴击率/暴击伤害

副词条：元素充能效率，元素精通，暴击率，暴击伤害

## **命座：**

**1.「唇啊，为我纺出歌与吟哦」**

说明：解放草元素奶，但如果本身队伍有水元素奶，则实际提升小很多。

**2. 「纺出那终北的告诫与述说」**

说明：给了绽放相关反应伤害提升，绽放队伍提升巨大，但提升不如妮露2命

**3.  「汝、切莫贪求狡狐的小径」**

说明：Q+3

**4. 「汝、切莫贪恋巨熊的权柄」**

说明：解放充能对菈乌玛很有用，团队提升巨大

**5. 「若是得以将真实之物见证」**

说明：E+3

**6. 「我愿将这血与泪奉予月明」**

说明：后台战技会额外造成一次基于菈乌玛元素精通的的月绽放范围伤害，额外提供反应增伤次数和刷新存在时间。释放元素战技会清除这种方式获得的层数。菈乌玛在元素爆发持续时间内的普攻会消耗对应层数造成基于精通的月绽放伤害。满辉状态下队伍中所有角色月绽放伤害提升。队伍不成熟提升较小。

# 配队推荐

菈乌玛的队伍构建需围绕**月兆满辉状态**和**高频水 / 雷元素附着**展开，核心思路是通过多角色触发月绽放反应，同时最大化利用其减抗增伤效果。以下为三类主流配队方案：

**1.菈乌玛 + 妮露 + 纳西妲 + 心海**

加入妮绽放作为辅助，提供减抗和增伤拐力，单人入队的情况下，月兆效果为初辉，还能够使妮绽种子产生暴击。

菈乌玛推荐携带纺月套，妮露2生2精通，草神草套，心海乐园套。

初辉效果下吃不满纺月套的特效，在还没刷出来或有毕业的成品时也可以使用饰金套。

**2.菈乌玛 + 妮露 + 白术 + 爱诺**

菈乌玛爱诺两名月兆角色入队，月兆效果为满辉，妮绽种子的伤害会略有降低，但菈乌玛本身的月绽放直伤

会更高，在没有草神有白术的情况下可以尝试。

菈乌玛穹境套 爱诺纺月套 妮露2生2精 白术草套

**3.菈乌玛 + 纳西妲 + 行秋 + 久崎忍**

菈乌玛战技的减草抗和元素爆发的增伤对超绽放同样生效，在缺少角色的低配情况下可以适用，全队仅需菈乌玛纳西妲本体2金就能玩。

纳西妲草套 菈乌玛纺月/饰金 行秋随意 久岐忍饰金/乐园

（菈乌玛加入超绽放队伍中其实不要草神三个人也和原本一样能玩，也可以替换艾尔海森站场输出，再低配一点加入爱诺也还行）

**4.菈乌玛 + 那维莱特 + 芙宁娜 + 希诺宁**

龙芙希三个人随便带一个能和水反应的角色帮那维莱特叠层都能用，带菈乌玛玩的话还可以吃到战技的减抗效果，在未来某些怪物机制需要月绽放反应时将菈乌玛作为对策卡加入龙芙。

（角色足够的情况下还是将龙芙和菈乌玛分两队玩比较好）
