**一、直傷月結晶的傷害公式**

（屬性 x 倍率 x 係數 x 基礎提升 x （元素精通 + 月增傷） + 羽毛傷害）x 爆擊 x 抗性 x 擢升

係數：月結晶的係數固定為 1.6 ，只要是直傷月結晶的傷害，都會自動乘上這個倍率。

基礎提升：茲白、少女的固有天賦一，月結晶反應基礎傷害提升，分別為14%與7%，加總為21%。

元素精通：數值大約為 6 x 茲白的總元素精通 / （2000 + 茲白的總元素精通）。

比較需要注意的有四件事

1. 茲白的天賦一和茲白的二命，與葉洛亞的Q技能是同個乘區，會互相稀釋。

2. 羽毛傷害跟以前閒雲、申鶴的計算方式不同，增傷乘區不會提升羽毛的傷害。

3. 月增傷和元素精通是同一個乘區。

4. 元素精通的公式應該是由玩家推算出來的，實際對比會發現有些許的誤差。

**二、實測茲白的技能傷害計算**

這部分會比較無聊一點，不想看實測的可以直接跳過第二部分，

反正只是驗證上述公式是否正確，以及更加瞭解上述公式的算法，

結論就這些

1. 五郎E的固定防禦吃的到隊伍加成月兆滿輝的效果，只要順序是五郎後接著茲白上場即可。

2. 葉洛亞四命的固定防禦、少女二命的固定防禦吃不到隊伍加成月兆滿輝的效果。

2. 訪月和穹境套的10%月增傷可以疊加為20%，當然訪月+訪月或穹境+穹境這樣就不行。

3. 茲白的天賦一與二命和葉洛亞的Q，吃不到倍率、係數、元素精通、月增傷。

4. 裁葉翠光的被動效果，不會算進直傷月結晶的傷害中，只會算進普通岩傷中。

5. 茲白的副詞條重要度，爆擊>>防禦>元素精通=元素充能。

那麼首先附上隊伍，之後會用這個隊伍的數值進行月結晶的傷害計算。

再來是EXCEL的計算

首先是茲白

[![]()](https://truth.bahamut.com.tw/s01/202604/forum/36730/4455582a2ed9ac32548d9c459da83dbe.PNG)[![]()](https://truth.bahamut.com.tw/s01/202604/forum/36730/6310ed917587b4ce0a6a0b2007559bff.PNG)

白值：也就是茲白的基礎防禦力957，這個數字的準確數值為956.85。

固定防禦：來自茲白聖遺物死之羽副詞條的23點防禦。

防禦百分比：花12.4+羽20.4+沙58.3+杯58.3+冠13.1+茲白天賦二30=192.5。

技能倍率：茲白13級靈駒飛踏第二段傷害的技能倍率253.7。

基礎提升：茲白固有天賦一的14%月結晶反應基礎傷害提升。

增傷乘區：茲白一命220+茲白二命30+穹境四件套10=260。

元素精通：花19+杯21+冠21+茲白天賦二60+穹境二件套80=201。

羽毛傷害：茲白總防禦力 x （茲白天賦一0.6 + 茲白二命5.5）。

爆擊率：之後會設定成100，就不計算了。

爆擊傷害：基礎50+角色突破38.4+花14.8+羽13.2+沙21+杯6.2+冠62.2+裁葉翠光88.2=294。

反應覆蓋率：為了方便計算就直接固定100了。

抗性：雙岩共鳴的20%岩元素減抗。

關於隊伍加成月兆滿輝的問題，我測試過了數次，最終得出的結論是

五郎這個老角色，他的E技能效果在五郎下場的時候，效果不會馬上失效，

葉洛亞四命的固定防禦與少女二命的固定防禦，只要角色一下場就馬上失效，

這就導致吃不到少女和葉洛亞的防禦BUFF。

測試方式為當所有BUFF都放完之後，讓茲白站場的瞬間進入角色面板查看五郎的當前防禦力。

**三、計算莉奈婭拐力與組隊選擇**

既然已經知道月結晶的計算了，那自然就能直接計算莉奈婭的BUFF能力，

不過這並沒有辦法計算副C傷害、月籠傷害，只是單純地計算出茲白單人的傷害提升，

也不能知道莉奈婭的產球、技能CD，會對排軸造成甚麼程度的影響，僅提供參考。

我這裡取茲白第二次靈駒飛踏的傷害來看

個人建議

要帶五郎還是葉洛亞，個人認為主要是看你聖遺物的爆擊，

優先考慮哪個爆擊乘區更高，也就是1+爆擊率\*爆擊傷害，哪個高優先帶哪個。

莉奈婭因為還有副C的傷害，以及聽說好像還不錯的產球量，

配合葉洛亞似乎可以讓茲白每次循環都開一次Q，

所以可以考慮放棄堆元素精通，改成堆元素充能了，

帶著莉奈婭+葉洛亞時，爆擊 > 防禦% >> 元素充能 > 元素精通 = 固定防禦，

元素精通和固定防禦提升的傷害量非常接近，如下圖可以看到，

有566元素精通時，聖遺物副詞條的一詞條固定防禦，提升的傷害就比一詞條元素精通還高了。

**四、怪物自帶元素時該如何應對**

因為有了千星奇遇的木樁存在，想必也已經有人測試過茲白在打自帶元素附著的敵怪時，

會發生哪些問題，我這邊還是列舉出來。

1. 無法召喚月籠。

2. 穹境四件套的30%爆擊率與10%月增傷完全觸發不到。

3. 打不出反應傷害的話，元素精通將會是完全無效的詞條，全隊聖遺物都要大幅調整。

4. 茲白E技能的讀條累積速度大幅降低，少女E技能讀條累積速度小幅降低。

5. 茲白的天賦一與二命的羽毛傷害，只有前兩次靈駒飛踏能夠觸發到。

以上這幾點就是導致玩家打自帶元素的敵怪時，打不出任何傷害的主因，

基本上不管怎麼改傷害都肯定會大打折扣，只能靠改變聖遺物來降低損失。

能做的有以下幾種改變

1. 聖遺物穹境套肯定得直接換成華館套或獵人套，這邊比較推薦華館套。

2. 茲白的輸出手法改成EEAAAAEQAAAAE就能下場了。

3. 茲白要保證能每軸都開Q。

4. 如果怪物是自掛火，能考慮多帶水傷副C來補傷害，其他同理。

雖然說月體系在打自帶元素的敵怪時，傷害都會大幅降低，

但茲白其實在這方面有蠻大的優勢的。

少女的引力值必須透過月反應傷害來堆疊，而茲白的普攻也能觸發直傷月結晶，

所以少女的E還是能正常打出傷害，2命少女一次循環的E觸發次數會從4次降低至3次而已，

並且茲白一命後，第一下E的傷害占比特別高，損失相對其他月體系來說較小，

但茲白的單人傷害量還是會降低40%以上，少女則是如上面說的，降低25%左右的傷害。
